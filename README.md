# WAEL.exe — Cyberpunk Portfolio

Single-page portfolio for Wael Mokaddem.

## Files

- `index.html` — page structure and content
- `style.css` — cyberpunk / futuristic gaming theme
- `script.js` — navigation, reveal animations, active section and contact form
- `assets/` — images used by the portfolio

## Run locally

Open `index.html` in your browser.

For a local server, use VS Code Live Server or:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Publish on GitHub Pages

1. Create or open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select the main branch and `/root`.
5. Save and wait for GitHub Pages to deploy.

## Customize

- Replace `assets/portrait.png` with another profile photo if desired.
- Add more screenshots in `assets/`.
- Update the LinkedIn URL in `index.html`.
- Add project repository links where marked.
